# AI Portfolio Project

This private repository contains the research, decisions, requirements, design, testing evidence, and implementation for an AI portfolio demonstration.

## Current status

The Northstar Ridge Equipment Readiness demo is now in implementation. The current
application is a responsive, public-facing foundation with placeholder entry points
for the Customer Service and Mechanic workflows.

## Run the application locally

Prerequisites:

- Node.js 20.9 or later
- npm 10 or later

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser. The demo currently
uses no API keys or environment variables.

### Verification commands

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
